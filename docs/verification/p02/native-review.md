复核对象为 [固定输入](../../../native/inputs.json)中的 `p02-session-host-v2`，核心 commit 为 `7592951b808c4839cb9d77cc4bc642f124915951`。本记录是实现阶段的源码与针对性测试复核，完整设备退出评审仍待完成；不授予 P00 候选生产批准，也不声称独立第三方审查。

## 已核对的边界

| 边界 | 实现与复核结果 | 验证范围 |
|---|---|---|
| 宿主与 runtime | 固定 FFI 上下文管理器复用进程 runtime；完整原生宿主不退化成 compact host。实际创建/退出钩子计数包含 worker 与阻塞池 | 双 ABI 构建、宿主回归；resources-05 的 50 轮固定 worker 为 2，fd 226～228 |
| 启动门槛 | 必须有 JNI protector 才创建会话；全局入口限单活动会话，闭合 gate 拒绝旧代次能力。未注册时补上拒绝，不继承上游放行语义 | bridge JVM 与 API36 实际 JNI 的拒绝/异常路径；实际 Service 的双外层 DNS 与既有回显 |
| TUN 接受与确认 | 有界队列保存 attachment 及回执；入队保持 Pending，实际安装完成才 Installed，失败停止 I/O 后标记 Failed | 宿主待安装队列取消；设备无效 fd 安装失败与 pipe 实际计数 |
| TUN 移除与替换 | 清理旧 NicCtx 等待 I/O JoinSet 排空，再发布旧 attachment Released。Kotlin 确认后关闭 PFD；新 attachment 使用递增身份 | 协调器虚拟时间顺序、实际 JNI 移除/替换与旧身份拒绝；平台参数重建设备场景待执行 |
| 停止与引用释放 | 停止先关闭回调 gate 并等待在途回调，删除实例、排空安装和后台命令后确认；关闭 PFD 后单独释放 JNI GlobalRef。临时 Arc 未排空则保持未知 | gate 宿主回归、设备两个并发停止各自确认、独立引用释放；未知释放阻止启动的领域回归 |
| DTO 与快照 | 生命周期 DTO 核对协议、会话、操作与 attachment；整数拒绝浮点、指数和溢出。未知核心状态不能用于确认安装/移除 | 精度与身份 JVM 回归；未知安装先复现后修复，未知移除按预算进入停止 |

## 尚未关闭的退出事项

固定版本的 UDP 本机关闭没有远端 FIN 确认。快速复用同一 IPv4 而新建随机 peer 身份时，远端旧连接尚未被探活移除，会产生暂时重叠路由。资源测试须同时核对对端连接与可达路由收束；有间隔资源循环不能替代无间隔重连结果。原失败轮次保留，不通过修改基线或删除失败请求获得通过。

policy-01 已实际通过 DHCP、TCP 外层默认路由绕行和配置失败后的恢复；resources-05 已完成带对端收束判据的 50 轮。network-03 已通过真实 Wi-Fi 恢复和物理 IPv6 正向基线/阻断；最终 APK 的 API24/37 基本生命周期和完整退出评审仍须逐项核对。完成前阶段保持 `in_progress`，不能发布全部 P02 已验收结论。源码版本及产物身份变化后重新执行受影响场景，不把旧设备结果迁移到新 APK。

实现与测试位置分别为 [原生桥](../../../native/README.md)、[所有权表](ownership.md)、[设备声明](../../../experiments/p02-vpn-core/experiment.json)与 [P02 实施记录](../../plan/p02-vpn-core.md)。
