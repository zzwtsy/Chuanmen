## 设备结果

- API36/arm64 真机：3 项 JNI 契约、TCP/UDP 外层分别承载 TCP/UDP 业务并重建 Activity、双外层正常系统 DNS 查询、真实 DHCP、TCP 外层默认路由与 MTU 应用、无效地址失败后的显式恢复、真实 Wi-Fi 恢复及手动停止后不重启。
- 50 轮：4 轮预热加 50 轮正式资源回归，108 次关联回答。固定 fd 基线 226、正式样本 226～228，共享 runtime worker 为 2；每轮停止后实例、借用、回调、JNI 引用、PFD 和额外观察者为 0。对端连接和可达路由也确认归零，最长收束 11305 ms。
- IPv6：普通未绑定物理网络的 TCP/UDP socket 在 VPN 前后分别获得受控全局 IPv6 对端回答；VPN 期间失败且对端没有对应请求。未改变 Private DNS、移动网络或宿主路由。
- API24/37 x86_64 模拟器：正常系统拒绝、取消后迟到授权、实际 TUN 安装、Activity 重建与停止。API37 另通过系统设置 Forget VPN，授权撤销、ServiceRevoked、零资源和通知移除均确认。此结果不代表模拟器业务流量或其他 OEM。

## 工程检查与未覆盖项

本地 `check-fast --offline`、25 项协调器和 4 项流量回归、正式 Service 集成、7 项原生宿主回归、3 项受控 DNS 解析器回归、Python 正负回归、固定版本 Ruff、actionlint 1.7.12、配置目录、严格文档结构、隐私及 P00 冻结完整性检查均通过。正式 APK 的两份实际原生库与本次构建一致，ELF 和 APK 16 KB 静态对齐通过；16 KB runtime 未验收。

[补丁评审](native-review.md)及其[来源身份](native-review.json)由实施者执行，live 构建拒绝缺失或过期评审；不声称独立审查或公开发行批准。P00 冻结记录和候选 `production_approved=false` 保留历史含义。

无间隔快速复用同一 IPv4 的 UDP 重连尚未验收。早期资源循环失败已保留：本机停止后远端旧 UDP peer 仍可能等待探活结束，期间重叠路由影响新连接；增加首个 TCP 连接预算没有消除该问题。本次 50 轮包含实际对端收束间隔，不能把该限定结果扩展为无间隔快速重连承诺。实际切网复验观测网络参数和会话稳定后发送一次业务请求，没有业务重发。

其他 OEM、16 KB runtime、长期性能与电量、完整 IPv6、Private DNS、持久化和进程恢复不在当前验收范围。最终阶段退出还需本次提交的远端 CI 通过和维护者评审；当前没有执行 Git 提交、推送、PR、合并或发布。
