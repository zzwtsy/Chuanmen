# 验证记录导航

本目录保存支撑明确结论的脱敏记录与必要输入，规则见 [验证规范](../development/verification.md)。阶段进度由 [路线图](../plan/ROADMAP.md) 维护，日常检查入口见 [开发环境](../development/setup.md)。

- [P00 技术可行性报告](p00/report.md)：固定产物和限定设备/网络下的既有结论、必要证据及缺口。
- [P00 退出边界](p00/report.md#未验证项与停止条件)：范围外门槛与生产接入限制；独立退出建议见 [复核记录](p00/reviews/independent-review.json)。
- [原型历史基线](prototype-baseline.json)：原始交互 QA、导出及名称调整，仅说明当时的原型验证对象；当前原型维护见 [原型说明](../../prototype/README.md)。

## 维护与冻结的边界

当前探针源码和工作流在 [experiments](../../experiments/android-vpn-smoke/README.md)。源码维护、离线回归、复建预览或新的模板构建均不继承历史 APK 的真机验收。

根 [handoff.json](../../handoff.json) 与 [SHA256SUMS](../../SHA256SUMS) 只覆盖 P00 所选阶段材料；其中状态字段是冻结时的运输信息，不描述当前产品进度。阶段 manifest 引用的记录和输入保持发布字节；更正、补测或新产物建立新记录与替代关系，不覆盖原记录。维护导航和现行规范可正常更新，不进入旧阶段冻结范围。

构建、临时运输、进度日志、缓存、完整日志和普通 CI 诊断输出进入忽略目录，普通 CI 结果通过具体运行定位，不持续追加到本目录。只有支撑技术结论、重要负向结果或阶段门槛的材料才筛选发布；原型修改不刷新 P00 运输清单。
